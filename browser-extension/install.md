# Quick Installation Guide

## Step 1: Open Browser Extensions

### Chrome/Edge/Brave:
- Go to `chrome://extensions/`
- Enable "Developer mode" (toggle in top-right)

### Firefox:
- Go to `about:debugging`
- Click "This Firefox"

## Step 2: Load Extension

### Chrome/Edge/Brave:
- Click "Load unpacked"
- Select the `browser-extension` folder

### Firefox:
- Click "Load Temporary Add-on"
- Select `manifest.json` from the `browser-extension` folder

## Step 3: Test

1. Go to `http://10.68.0.49:30082` (your Rocket.Chat)
2. Look for "🚀 Social Hub" button in top-right corner
3. Click it to open `http://localhost:8080/feed`

## Done! 🎉

The extension will now add a Social Hub button to your Rocket.Chat interface.
